\begin{frame}{Problem}
  \begin{block}{Question}
    When a small language model receives long, noisy retrieved context, can pruning make its answer more faithful to the evidence?
  \end{block}

  \vspace{0.5em}
  \begin{itemize}
    \item Task: conversational open-domain question answering with RAG.
    \item Main benchmark: QReCC, where each question depends on previous conversation turns.
    \item Output: short answer generated from retrieved/pruned evidence and retained dialogue history.
    \item Main risk: the model may keep stale history, miss the current evidence, or hallucinate unsupported claims.
  \end{itemize}
\end{frame}

\begin{frame}{Why Pruning Matters}
  \begin{columns}[T,onlytextwidth]
    \column{0.52\textwidth}
    \textbf{Long context is not free.}
    \begin{itemize}
      \item More tokens increase latency and memory cost.
      \item Retrieved passages and old dialogue turns often contain near-misses, stale entities, and distractors.
      \item Small LMs are especially sensitive to noisy evidence.
    \end{itemize}

    \column{0.44\textwidth}
    \textbf{Long context is not always used well.}
    \begin{itemize}
      \item Liu et al. show that models often perform best when relevant information is near the beginning or end of the context.
      \item Performance can drop when evidence is in the middle, even for long-context models.
    \end{itemize}
  \end{columns}

  \vspace{0.5em}
  \footnotesize Source: Liu et al., TACL 2024, ``Lost in the Middle''.\footnote{\url{https://aclanthology.org/2024.tacl-1.9/}}
\end{frame}

\begin{frame}{Related Work Signals}
  \begin{itemize}
    \item \textbf{RECOMP}: compresses retrieved documents before generation; reports compression rates as low as 6\% with minimal performance loss in evaluated settings.\footnote{\url{https://proceedings.iclr.cc/paper_files/paper/2024/hash/bda88ed2892f5e61c9a9bf215c566913-Abstract-Conference.html}}
    \item \textbf{LLMLingua-2}: formulates prompt compression as token classification and reports 1.6--2.9$\times$ end-to-end latency acceleration at 2--5$\times$ compression.\footnote{\url{https://huggingface.co/papers/2403.12968}}
    \item \textbf{Provence}: treats context pruning as sequence labeling and reports negligible to no performance drop at almost no additional RAG pipeline cost.\footnote{\url{https://arxiv.org/abs/2501.16214}}
  \end{itemize}

  \vspace{0.5em}
  \begin{block}{Our angle}
    We use QReCC because the central problem is conversational: deciding which past turns and retrieved passages still matter for the current question.
  \end{block}
\end{frame}

\begin{frame}{What We Learned}
  \begin{itemize}
    \item \textbf{Pruning can improve faithfulness}, but not every pruning method helps equally.
    \item \textbf{Aggressive compression is dangerous for conversational QA}: if the relevant history turn disappears, the current question becomes ambiguous.
    \item \textbf{Faithfulness and correctness are different}: a faithful answer can still be the wrong answer, and a correct short answer can be judged poorly.
    \item \textbf{Exact coverage is too strict for token compression}: LLMLingua-2 may fragment evidence so gold sentences no longer match verbatim.
    \item \textbf{Conversation history is not just extra text}: old turns can help or distract depending on the current question.
  \end{itemize}
\end{frame}

\begin{frame}{CfC Extension: The Core Idea}
  \begin{block}{Where the idea came from}
    When reading dense, information-rich text, humans slow down.
    High-entropy words take longer to process because they carry more
    unexpected information. Can we use this same signal to decide
    which conversation turns deserve more ``processing time'' in a neural network?
  \end{block}

  \vspace{0.4em}
  \begin{itemize}
    \item Fixed thresholds do not know whether a turn is easy, noisy, redundant, or depends on earlier dialogue.
    \item We explore Closed-form Continuous-time networks (CfCs): temporal dynamics without a heavy ODE solver.\footnote{\url{https://www.nature.com/articles/s42256-022-00556-7}}
    \item Key insight: map per-turn \emph{surprisal} to a continuous time step $\Delta t_i$, so surprising turns get a wider integration window in the network's ODE.
  \end{itemize}
\end{frame}

\begin{frame}{Cognitive Motivation: Reading Time $\propto$ Surprisal}
  \begin{block}{Surprisal theory (psycholinguistics)}
    Reading time on a word is proportional to its surprisal $-\log P(w_j \mid w_{<j})$.
    A word that violates expectations takes more cognitive effort to integrate.
  \end{block}

  \vspace{0.4em}
  \begin{itemize}
    \item Levy (2008): syntactic surprisal predicts word-by-word reading times.
    \item Smith \& Levy (2013): the relationship is \emph{logarithmic} and holds across many corpora.
    \item \textbf{Transfer to NLP:} if a turn is lexically surprising (high surprisal from a proxy LM), it likely introduces new information — and is more likely to be important for answering the current question.
    \item We do not claim surprisal \emph{equals} importance; we ask whether it is a \emph{useful proxy} — and test this with a simulation before training.
  \end{itemize}

  \vspace{0.3em}
  \footnotesize
  Levy 2008, Cognition 106(3).\quad Smith \& Levy 2013, Cognition 128(3).
\end{frame}

\begin{frame}{From Reading Time to the CfC Time Step}
  \small
  For utterance $u_i$, compute surprisal with DistilGPT-2 (proxy LM):
  \[
    S(u_i) = -\frac{1}{N}\sum_{j=1}^{N}\log P(w_j \mid w_{<j})
  \]

  Map surprisal to a continuous time step (rank-normalised for outlier robustness):
  \[
    \Delta t_i = \Delta t_{\min} + \beta \cdot \frac{\text{rank}(S_i)}{T}
  \]

  The CfC network then integrates over $\Delta t_i$ at each turn.
  The \emph{commitment fraction} measures how strongly the state ``locks on'':
  \[
    \varphi_i = 1 - e^{-\lambda \Delta t_i}
  \]

  \begin{itemize}
    \item Large $\Delta t_i$ $\rightarrow$ large $\varphi_i$ $\rightarrow$ turn leaves a stronger trace in the hidden state $\rightarrow$ higher importance score.
    \item Rank normalisation prevents one outlier surprisal from dominating the time budget (validated by Simulation S5).
  \end{itemize}
\end{frame}

\begin{frame}{Why Simulations Before Training?}
  \begin{columns}[T,onlytextwidth]
    \column{0.50\textwidth}
    \textbf{The risk}
    \begin{itemize}
      \item Surprisal may not correlate with true turn importance on QReCC at all.
      \item If that correlation $\rho \approx 0$, entropy adds no signal and training compute is wasted.
      \item $\beta$, $\Delta t_{\min}$, $\tau$ all change faithfulness but are expensive to tune end-to-end with a 7B teacher.
    \end{itemize}

    \column{0.46\textwidth}
    \textbf{The strategy}
    \begin{itemize}
      \item Seven \emph{model-free} simulations, each isolating one design question.
      \item Each one returns a concrete config value or a falsifiable go/no-go threshold.
      \item Train only if every simulation passes --- otherwise the idea is rejected cheaply.
    \end{itemize}
  \end{columns}

  \vspace{0.6em}
  \begin{block}{Reading the figures}
    Across the suite, the recurring metric is \emph{importance recovery} ---
    Spearman correlation between a method's per-turn score and the true latent
    turn importance $u$. Higher means the pruner keeps the turns that matter.
  \end{block}
\end{frame}

\begin{frame}{Entropy-Driven CfC Pruning: Architecture}
  \small
  \textbf{Simulation outputs $\rightarrow$ model design.}

  \vspace{0.4em}
  \begin{itemize}
    \item \textbf{Input per turn:} SBERT embedding (dim 384) + rank-normalised $\Delta t_i$ from DistilGPT-2 surprisal.
    \item \textbf{Hidden dynamics:} CfC cell; state $h_i$ integrates over $\Delta t_i$ (wider window = stronger commitment).
    \item \textbf{Per-turn readout:} $\hat{p}_i = \sigma(W h_i + b)$, importance $\in [0,1]$.
    \item \textbf{Teacher labels:} answer-conditioned leave-one-out $\Delta$NLL of the gold answer, scored with a lightweight LLM (Qwen2.5-1.5B-Instruct).
    \item \textbf{Loss:} MSE between $\hat{p}_i$ and the normalised teacher importance.
    \item \textbf{Pruning:} discard turns where $\hat{p}_i < \tau$, with $\tau = 0.5$.
  \end{itemize}

  \vspace{0.3em}
  \begin{tabular}{lll}
    $\Delta t_{\min} = 0.05$ & $\beta = 1.0$ & $\tau = 0.5$ \\
    \multicolumn{3}{l}{\small ($\beta$, $\Delta t_{\min}$ from simulations; $\tau$ at the default 0.5)}
  \end{tabular}
\end{frame}

\begin{frame}{Why the CfC Run Failed}
  \small
  \begin{tabular}{p{0.30\textwidth}p{0.58\textwidth}}
    \toprule
    Failure point & Evidence from this run \\
    \midrule
    Weak proxy channel & Surprisal--teacher Spearman mean is $-0.074$, below the $\rho^*=0.1$ go/no-go threshold. \\
    Target sparsity / threshold mismatch & At $\tau=0.5$, recall stays below 0.03; almost all positive teacher turns are missed. \\
    Overfitting without useful validation gain & Train loss falls, while validation loss is flat and then worsens after epoch 6. \\
    No completed downstream comparison & The run produced training/proxy figures, but not \texttt{eval\_results.json}; we cannot claim ROUGE or token-reduction wins. \\
    \bottomrule
  \end{tabular}

  \vspace{0.65em}
  \begin{block}{Interpretation}
    The CfC mechanism is still mathematically valid, but this experiment rejects the stronger claim that DistilGPT-2 surprisal is a reliable importance proxy for QReCC history turns.
  \end{block}
\end{frame}

\begin{frame}{Conclusion}
  \begin{block}{Main finding}
    Context pruning is useful, but the best pruner is not simply the most aggressive one.
  \end{block}

  \begin{itemize}
    \item LLMLingua-2 gave the best corrected faithfulness score in our pilot runs.
    \item Combined pruning showed the strongest compression/noise reduction in pilot runs, but removed too much supporting evidence.
    \item CfC-style adaptive pruning is our next step for deciding \emph{when} context should be preserved, compressed, or forgotten.
  \end{itemize}
\end{frame}
